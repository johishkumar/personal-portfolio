## 🛠️ Tech Stack

- **Frontend:** React / Next.js
- **Language:** JavaScript / TypeScript

- **Version Control:** Git & GitHub

## 🚀 Getting Started

### Installation

```bash
git clone https://github.com/johishkumar/personal-portfolio.git
cd personal-portfolio
npm install
npm run dev
```

### Production Build

```bash
npm run build
npm run start
```
